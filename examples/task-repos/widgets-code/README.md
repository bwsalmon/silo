# widgets

A small command-line tool and library for describing widgets. This is the
code's own README: it has no front matter, and it is not a task-repo
object. The repo's grain folder is [`.grain/`](.grain/README.md), and its
grain settings are in [`.grainconfig`](.grainconfig).

(This repo stands for `https://git.example.com/hub/widgets.git` in the
task-repos examples, docs/task-repos.md §3.6.)
